Steps:
1. Read in all Exp as well as Rec implementations
	-> Only keep information about the implementation method + method parameters (e.g. addr_width), RMSRE, LUT, DSP
	-> Only keep if RMSRE > 1e-7
	-> Only keep points on the pareto-front (better means smaller in at least one of RMSRE, LUT or DSP)
	-> put everything in a combined file: exp.csv and rec.csv
2. Take all combinations of remaining Exp & Rec implementations to form a softmax implementation
	-> compute RMSRE based on the following formula: RMSRE(softmax)^2 = RMSRE(exp)^2 + RMSRE(rec)^2 + RMSRE(other)^2 with RMSRE(other) := 1.918e-7
	-> compute the resources (LUT, DSP) for this implementation based on the following formula: 1*Resources (Rec) + SIMD*Resources (Exp) + 1*Resources (Base)
		-> Rec and Exp resources are read from the corresponding implementation
		-> Base resources are determined from the SIMD_sweep.csv resource file: This file contains the total softmax resources as a function of SIMD
		-> To get the base resources you have to subtract 1*Resources (Rec_Base) + SIMD*Resources (Exp_Base) with the base cases defined by:
			-> Rec: Bipartite, AW0=3, AW1=AW2=4, WW=14, NUM_NEWTON_STEPS=1
			-> Exp: Splitting, AW0=AW1=AW2=6,WW=22
			-> If these not exist, immediately throw an error
	-> once all RMSRE, LUT and DSP are computed: Only keep points on the pareto-front (including RMSRE, LUT and DSP as in step 1)
	-> put in a combined file: softmax.csv
3. Take all the pareto optimal softmax implementations
	-> plot them in a combined figure with RMSRE on the x-axis, LUT on the y-axis and DSP represented by different symbols
	-> don't care about the underlying method and method parameters for now
	-> store in a single file: diagram.png
