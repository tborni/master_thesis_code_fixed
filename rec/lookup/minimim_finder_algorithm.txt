============================================================
OPTIMAL "a" FOR NEWTON-RAPHSON RECIPROCAL SEED (per LUT interval)
GLOBAL-MINIMUM-GUARANTEED SPECIFICATION
============================================================

PROBLEM
-------
For inputs x in [x_min, x_max] (with 0 < x_min < x_max), we
approximate 1/x with ONE generalized Newton step:

    newton(x, a, c) = a * (c - x * a)

We must choose the per-interval seed constant "a" that MINIMIZES
the integrated squared error over the interval:

    E(a) = integral_{x_min}^{x_max} ( 1/x - a*(c - x*a) )^2 dx

c is a given constant (generalization of the usual 2.0).

The task: compute the "a" that is the GLOBAL real minimizer of
E(a). Not a local minimum. This spec tells you exactly how to
guarantee that.

------------------------------------------------------------
STEP 0 — INTERVAL MOMENTS (constants for this interval)
------------------------------------------------------------
Define M_i = integral_{x_min}^{x_max} x^i dx. Compute:

    M_2  = (x_max^3 - x_min^3) / 3
    M_1  = (x_max^2 - x_min^2) / 2
    M_0  =  x_max - x_min
    M_m1 =  log(x_max / x_min)          // "M_-1", natural log
    M_m2 =  (1/x_min) - (1/x_max)       // "M_-2"

Guaranteed for any valid interval: M_2 > 0 and M_0 > 0.

------------------------------------------------------------
KEY STRUCTURAL FACTS (why a global min always exists)
------------------------------------------------------------
E(a) expands to a QUARTIC in a:

    E(a) = M_m2
         + (c^2 + 2)*M_0 * a^2
         + M_2 * a^4
         - 2*c*M_m1 * a
         - 2*c*M_1  * a^3

Because the leading coefficient M_2 > 0, E(a) -> +infinity as
a -> +/-infinity. Therefore E has a FINITE REAL GLOBAL MINIMUM.

Its derivative is a CUBIC:

    f(a)  = 2*M_2*a^3 - 3*c*M_1*a^2 + (c^2+2)*M_0*a - c*M_m1
    f'(a) = 6*M_2*a^2 - 6*c*M_1*a   + (c^2+2)*M_0

A cubic has either 1 or 3 real roots. Because the quartic opens
upward:
  - 1 real root  -> it is THE global minimum (no other critical pt)
  - 3 real roots -> they order as [min, max, min]; exactly TWO
                    local minima compete. Global = smaller E of the two.

So there are AT MOST TWO minimum candidates to compare. Ever.

The second-derivative test: a critical point a* is a minimum iff
    d2E/da2 = 2 * f'(a*) > 0   i.e.   f'(a*) > 0.
The middle root of a 3-root set has f'(a*) < 0 (it's the maximum)
and must be rejected.

============================================================
ALGORITHM (guarantees the global real minimum)
============================================================
Implement EXACTLY this. It never relies on a lucky seed and never
misses a root, because it brackets all roots analytically.

--- STEP 1: Detect how many critical points the cubic has -------
Compute the discriminant of f'(a) (the inner parabola):

    disc_fp = (6*c*M_1)^2 - 4*(6*M_2)*((c^2+2)*M_0)
            = 36*c^2*M_1^2 - 24*M_2*(c^2+2)*M_0

  IF disc_fp <= 0:
      f'(a) >= 0 everywhere -> f(a) is monotonic -> exactly ONE
      real root -> it is automatically the GLOBAL minimum.
      Go straight to STEP 3 with a single bracket spanning all a
      (see STEP 2 fallback), or just Newton-solve f from seed
      a0 = c / (x_min + x_max) and skip to STEP 4 with one candidate.

  IF disc_fp > 0:
      f has three real roots (or a double root). There are two
      inner critical points of f at:
          r = sqrt(disc_fp)
          aL = (6*c*M_1 - r) / (12*M_2)     // local MAX of f-shape
          aR = (6*c*M_1 + r) / (12*M_2)      // local MIN of f-shape
      with aL < aR. These bracket f's roots:
          root_1 in (-inf, aL]
          root_2 in [aL, aR]
          root_3 in [aR, +inf)
      Proceed to STEP 2 to extract all three.

--- STEP 2: Find ALL real roots by bracketed root-finding --------
Use a bracketing method (bisection, or safeguarded Newton that
falls back to bisection) — NOT bare Newton — so convergence is
guaranteed and basin-independent.

Root-find f(a)=0 in each bracket. To get finite outer brackets,
expand outward from aL and aR until the sign of f differs:

    // lower root: search left of aL
    lo = aL; step = max(1.0, abs(aL))
    while sign(f(lo)) == sign(f(aL)):  lo -= step; step *= 2
    root_1 = bisection(f, lo, aL)

    // middle root: already bracketed by [aL, aR]
    root_2 = bisection(f, aL, aR)

    // upper root: search right of aR
    hi = aR; step = max(1.0, abs(aR))
    while sign(f(hi)) == sign(f(aR)):  hi += step; step *= 2
    root_3 = bisection(f, aR, hi)

Bisection target tolerance: |f(a)| < 1e-12 or interval width
< 1e-14 * max(1, |a|). Use double precision throughout.

(If disc_fp <= 0 in STEP 1, instead bracket the single root:
 start from a0 = c/(x_min+x_max), expand a symmetric window
 [a0-step, a0+step], doubling step until f changes sign across it,
 then bisection. That root is the global min; go to STEP 4.)

--- STEP 3: Keep only genuine minima (reject the maximum) ---------
For each root found, evaluate f'(root):
    keep it as a candidate IFF  f'(root) > 0.
In the 3-root case this discards root_2 (the maximum) and keeps
root_1 and root_3. In the 1-root case the single root is kept.

--- STEP 4: Select the GLOBAL minimum by comparing E -------------
For every kept candidate a_cand, compute:

    E(a_cand) = M_m2
              + (c^2+2)*M_0 * a_cand^2
              + M_2 * a_cand^4
              - 2*c*M_m1 * a_cand
              - 2*c*M_1  * a_cand^3

Return the a_cand with the SMALLEST E value. This is the
guaranteed GLOBAL real minimizer of E(a).

(Tie-breaking, essentially never needed: if two candidates give
E equal within 1e-12, prefer the one with smaller |a| for numeric
stability of the downstream Newton step.)

============================================================
REFERENCE IMPLEMENTATION (pseudocode / language-agnostic)
============================================================

function optimal_a(x_min, x_max, c):
    # STEP 0
    M2  = (x_max**3 - x_min**3) / 3
    M1  = (x_max**2 - x_min**2) / 2
    M0  =  x_max - x_min
    Mm1 =  log(x_max / x_min)
    Mm2 =  1/x_min - 1/x_max

    A3 = 2*M2
    A2 = -3*c*M1
    A1 = (c*c + 2)*M0
    A0 = -c*Mm1

    def f(a):   return ((A3*a + A2)*a + A1)*a + A0
    def fp(a):  return (3*A3*a + 2*A2)*a + A1
    def E(a):
        return (Mm2 + A1*a*a + M2*a**4          # note A1 == (c^2+2)*M0
                - 2*c*Mm1*a - 2*c*M1*a**3)

    def bisect(lo, hi):
        flo = f(lo); fhi = f(hi)
        assert flo == 0 or fhi == 0 or sign(flo) != sign(fhi)
        for _ in range(200):
            mid = 0.5*(lo + hi)
            fm = f(mid)
            if abs(fm) < 1e-12 or (hi - lo) < 1e-14*max(1, abs(mid)):
                return mid
            if sign(fm) != sign(flo):
                hi = mid
            else:
                lo = mid; flo = fm
        return 0.5*(lo + hi)

    # STEP 1
    disc_fp = A2*A2 - 3*A3*A1        # == (2*A2/2)^2 form; equals
                                     # 9c^2M1^2 - 3*2M2*(c^2+2)M0
    # (equivalently 36c^2M1^2 - 24 M2 (c^2+2) M0, same sign)

    candidates = []

    if disc_fp <= 0:
        # single real root -> global min
        a0 = c / (x_min + x_max)
        step = max(1.0, abs(a0))
        lo, hi = a0 - step, a0 + step
        while sign(f(lo)) == sign(f(hi)):
            step *= 2; lo = a0 - step; hi = a0 + step
        root = bisect(lo, hi)
        candidates.append(root)
    else:
        r  = sqrt(disc_fp)
        aL = (-A2 - r) / (3*A3)      # -A2 = 3cM1 ; matches (6cM1 - 2r?) 
        aR = (-A2 + r) / (3*A3)
        # NOTE: with A3=2M2, A2=-3cM1: aL,aR = (3cM1 -/+ r)/(6M2).
        # Ensure aL < aR (swap if needed).
        if aL > aR: aL, aR = aR, aL

        # lower bracket
        step = max(1.0, abs(aL))
        lo = aL - step
        while sign(f(lo)) == sign(f(aL)):
            step *= 2; lo = aL - step
        candidates.append(bisect(lo, aL))

        # middle root
        candidates.append(bisect(aL, aR))

        # upper bracket
        step = max(1.0, abs(aR))
        hi = aR + step
        while sign(f(hi)) == sign(f(aR)):
            step *= 2; hi = aR + step
        candidates.append(bisect(aR, hi))

    # STEP 3: keep minima only
    minima = [a for a in candidates if fp(a) > 0]
    # safety: if numerical fp(a)==0 slips through, keep and let E decide
    if not minima:
        minima = candidates

    # STEP 4: global by smallest E
    best = minima[0]
    best_E = E(best)
    for a in minima[1:]:
        Ea = E(a)
        if Ea < best_E:
            best, best_E = a, Ea
    return best

============================================================
CORRECTNESS GUARANTEES (why this cannot return a local min)
============================================================
1. E(a) is quartic with positive leading term -> a finite real
   global minimum provably exists.
2. All critical points are roots of the cubic f. We find EVERY
   real root because the roots of f' (computed in closed form)
   bracket the roots of f, and bisection on a sign-changing
   bracket always converges to the contained root.
3. Every minimum among them is retained (f'(a) > 0 test); the
   lone maximum in the 3-root case is the only thing discarded.
4. The global minimum is, by definition, the retained candidate
   with the smallest E(a) — and we compare all of them.
Hence the returned "a" is the GLOBAL real minimizer.

VALIDATION HOOKS (recommended tests to add):
 - Assert f(returned_a) is near 0 (it's a true critical point).
 - Assert fp(returned_a) > 0 (it's a minimum).
 - Brute-force check: sample E(a) on a dense grid over
   [returned_a - 4|returned_a| - 1, returned_a + 4|returned_a| + 1];
   confirm no sampled E is smaller than E(returned_a) beyond a
   1e-9 tolerance. Use this in unit tests, not in production.
 - Edge test: very narrow interval (x_max ~ x_min) and very wide
   interval; confirm disc_fp branch selection behaves and the
   returned a tracks ~ 1/x_mid in magnitude.

NUMERICAL NOTES:
 - Use double precision (fp64) for the whole solve; the seed "a"
   is later stored/used for the fp32 datapath, but SOLVE in fp64.
 - log is natural log.
 - Guard x_min > 0 strictly (M_m1, M_m2 require it).
 - c is typically ~2.0; the code makes no assumption on c beyond
   it being a finite real constant.
